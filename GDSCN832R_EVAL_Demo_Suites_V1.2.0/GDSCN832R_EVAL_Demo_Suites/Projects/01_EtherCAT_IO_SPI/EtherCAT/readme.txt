   This directory is related to the EtherCAT protocol stack. 
The ConfigFile directory is used to store configuration files for importing into the SSC tool, 
while the Src directory is used to store the protocol stack code generated by the SSC tool. 
For detailed instructions on how to port the protocol stack code, refer to the AN246 document in the DOC directory.

   Before using the EVAL board, please ensure that the corresponding configuration file has been downloaded to the EEPROM on the development board. 
If the relevant configuration file has not been updated, please refer to the EEPROM update section in Document AN246 to update the relevant XML file.
